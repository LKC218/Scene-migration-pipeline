# 通用入口模块说明

## 职责与依赖方向

`项目入口.py` → `项目配置.py`；执行时通过独立子进程调用 `scripts/诊断/运行独立审计.py`。后者在 Max 中运行 `场景审计.py` 或 `材质依赖审计.py`。离线依赖分析独立消费 JSON。

`分享工具包.py` 只复用配置模块的工具包根目录常量，读取白名单；验证模块单向调用通用模块。没有对案例转换、优化或 Unity 工程的依赖，也没有要求旧模块反向依赖通用入口。

## 配置和命令

字段、相对路径和退出码见 [环境与配置](../执行规范/环境与配置.md)。本层仅支持 schema_version=1，拒绝未知字段和重复键，插件变量限定为目录配置。

check 和 plan 无业务文件写入。audit 默认预览，只有 --execute 启动独立审计。命令采用参数数组和隐藏子进程，不更改系统环境，不自动重试。

输出仅允许工具包 output/过程资产 下的新批次，禁止与源目录或额外保护目录重叠。底层审计再次检查保护边界并独占创建输出目录。本层不提供删除、覆盖或续写批次功能。

## 审计数据契约

基础审计提供 scene、nodes、materials、texture_graph、bitmap_textures、assets、summary 和 status。详细审计附带 material_details 与 material_detail_status；read_error、not_lossless 和 partial 必须保留并解释。

运行记录包含源哈希、保护范围前后快照、Safe Scene 参数、退出码和实际耗时；报告失败或保护发生变化时阻塞。无阻塞状态只代表需要继续材质映射评估。基础审计对部分属性读取有容错，不是所有源节点的完整序列化证明。

独立审计不自动冻结场景或贴图、不重链接资源。唯一同名贴图候选仍需重链接验证；报告中的候选不能当作已经恢复。未知 Max 类、版本及渲染器差异需要真实场景测试。

## 分享校验

仓库的.gitignore排除用户资产与输出，.gitattributes统一LF换行。白名单允许这两个Git约定文件，其他隐藏文件仍不放行。发布与大资产分离规则见 [仓库发布与资产管理](../执行规范/仓库发布与资产管理.md)；新增文件先登记，提交前核对真实清单，推送后从干净远程副本复测。

### 六步指南的同源生成

文档规范与导航见 [文档总入口](../README.md) 和 [文档管理规范](../执行规范/文档管理规范.md)。指南和图示按用途放在使用指南目录，执行规则与模板分开；迁移后生成器和分享白名单以新路径为准，不读取旧迁移指引作为内容源。

`docs/使用指南/场景迁移与优化-六步指南.md`是内容依据；`生成六步指南.py`使用固定模板生成同名HTML。生成器仅支持本指南约定的标题、段落、列表和引用，不是通用Markdown渲染器；输入全部转义，拒绝缺少步骤或字段，避免将源文档HTML解释成可执行内容。

维护命令：`python -X utf8 -B scripts/通用/生成六步指南.py`；只读校验加`--check`。模板位于`scripts/通用/模板/六步指南页面.html`；正文只改Markdown，布局或交互改模板，再重新生成。生成不启动浏览器或三维软件。

页面无外部字体、图片、脚本和网络请求；CSP禁止连接外部服务。默认仅显示当前一步与最多三条用户事项，技术说明、完成标准、异常处理和完整话术通过原生details按需展开。上一步、下一步和导航更新当前阅读步骤及地址锚点，支持浏览器前后切换；不控制任务执行。

第04、06步额外提供源Markdown定义的修改意见模板，对应两个独立复制按钮。复制受限时显示可手动复制的文字；复制不改变当前步骤或批准状态。不再读取或写入localStorage，不再显示勾选或完成计数；已有旧浏览器记录不主动删除。无脚本时通过noscript恢复六步顺序阅读，复制按钮保持禁用。

分享白名单仅放行指定页面、固定模板和指定Node测试文件，不开放任意HTML。分享校验用包内Markdown和模板重新渲染，要求HTML字节完全一致；源码模板属于需审查的受信任代码，这不是任意HTML安全审计器。HTML文件内不包含模型或Unity连接信息。

Python测试验证六步结构、转义、链接、默认仅一步可见、事项数量上限和生成一致性；Node标准库测试使用模拟DOM、地址锚点和剪贴板验证切步、边界、复制与回退，不等于真实浏览器或视觉验收。Node只用于维护测试，打开HTML不需要Node；基础审计仍仅需Python标准库。

白名单只能列出受支持的文本文件，拒绝危险路径和缓存／资产目录；逐项读取，不递归收集项目。打包前校验语法、链接及有限的敏感信息模式，打包后复核内置清单。详见 [分享与验证](../执行规范/分享与验证.md)。

美术手册及 [流程图](../使用指南/图示/场景迁移与优化-流程图.svg) 随白名单分发。仅放行这一确定路径的静态SVG，解析并限制元素与属性，不允许脚本、外部资源、事件、嵌入HTML、实体声明或其他SVG文件；不扩大为任意图片或模型资产打包。

美术手册和 [Agent执行约定](../执行规范/场景迁移与优化-Agent执行约定.md) 约束两次视觉确认及Unity Skills连接。它们不新增转换或Unity调度命令，不影响原审计接口；真实Unity操作仍由执行端技能提供。

检查链接仅验证文件目标，不验证章节锚点、网址或代码片段中的路径。安全扫描不能替代人工分发审核。

## 回归测试

运行 `python -X utf8 -B scripts/验证/测试通用入口.py`，覆盖配置类型、路径隔离、预览无副作用、显式执行与退出码传递、打包限制和独立目录自检。另运行两组既有诊断规则测试。

测试不启动 Max、Blender 或 Unity；真实审计和视觉验证需另外授权和执行。禁止用静态成功标记模型转换通过。
