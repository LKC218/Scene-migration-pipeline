# Agent接入指南

## 阅读顺序

[README](../../README.md) → [AGENTS](../../AGENTS.md) → [快速开始](快速开始.md) → [环境与配置](../执行规范/环境与配置.md) → [标准流程](../执行规范/三维场景转换与游戏优化-标准流程.md) → [代码导航](../apps-code-map.md)。

无法自动识别 AGENTS.md 的 Agent，也可由用户要求显式读取。基础审计不要求安装个人技能或指定模型；Unity阶段需具备Unity Skills，具体边界见 [场景迁移执行约定](../执行规范/场景迁移与优化-Agent执行约定.md)。

美术用户通过 [美术操作流程](场景迁移与优化-美术操作流程.md) 提供资料与确认效果。不要让其处理命令行或JSON；由Agent在获准范围内完成配置，必要时只询问实际文件、软件和效果要求。

## 首轮收集

询问或从用户明确提供的配置中核实：源场景与资源目录、软件版本与路径、需要保护的资产、目标格式、目标引擎／设备、允许近似范围和质量预算。不要从历史报告推断本轮授权。

缺少 Max 或输入时，仍可运行离线测试并完成方案；不能伪造成功报告。已有 Blender 母版或 GLB 任务不应硬套 Max 配置，先按标准流程审查，再建立经过测试的独立适配入口。

## 执行约定

1. 配置检查和执行预览。
2. 展示将读取和写入的位置、风险与限制，获取本任务执行确认。
3. 运行安全审计，保留原退出码和日志。
4. 检查保护哈希、输入身份及阻塞项，提出下一阶段材质小样方案。
5. 转换方案批准后才实现场景适配；不调用白名单外案例脚本作为默认回退。

本期分享包没有统一 Blender 转换命令。Agent 可以据审计数据开发适配，但必须先分析和测试，不能把工具包名称理解为已实现所有转换器。

## 必须停下的情况

输入版本变化、输出路径重叠、既有批次冲突、缺失插件或资源、参数部分读取、授权不清、非零退出码、保护文件发生变化。报告“已知事实、影响、下一步需要什么”，不要反复运行相同失败命令。

## 可直接复制的请求

> 阅读本项目的 Agent 约定和快速开始，检查配置并给出安全审计预览。先不要启动三维软件。确认输入、目标、保护范围和缺失环境后，给我实施方案。

> 我批准刚才预览的安全审计。只执行审计并保留证据，不做材质替换、减面、软件安装或引擎写入。结束后报告阻塞项和下一阶段建议。

## 交接输出

填写 [执行记录模板](../文档模板/三维场景转换与游戏优化-执行记录模板.md)，给出输入身份、执行参数、工具版本、日志、输出哈希、分层结果和唯一下一步。失败和未验证项必须保留，不把历史案例证据混入本轮验收。
