# 快速开始

本页的配置与命令供Agent或技术人员使用。美术人员直接阅读 [美术操作手册](场景迁移与优化-美术操作流程.md) 和 [流程图](图示/场景迁移与优化-流程图.svg)，无需手动执行以下命令。

更简洁的入口：[六步HTML](场景迁移与优化-六步指南.html)；把 [同内容Markdown](场景迁移与优化-六步指南.md) 交给Agent即可。HTML不需要运行服务器或安装依赖。

## 先确认你拿到的是什么

这是安全审计工具包和转换协作规范，不包含 Max、Blender、插件、客户模型和历史案例。通用命令只自动执行 Max 审计；后续材质转换由 Agent 根据审计结果适配。

没有 Max 也可以运行离线自检、阅读流程和准备配置。实际审计首期只支持 Windows。

## 准备环境

- 外部 Python 3.10+，能运行 `python --version`。通用入口与离线测试仅使用标准库，无需 pip 安装。
- 真实审计需要已安装、可使用的 3ds Max 和实际 `3dsmaxbatch.exe`；插件与渲染授权按源场景另行确认。
- Blender 是后续迁移工具，不是运行离线检查的前提。
- 不要在运行前递归安装历史脚本的所有依赖。详见 [环境与配置](../执行规范/环境与配置.md)。

## 填写本机配置

在工具包根目录将 `configs/项目配置.example.json` 复制为 `configs/项目配置.local.json`，由编辑器或 Agent 填写：

- `scene`：待审计 .max 的实际路径，建议使用已核对哈希的独立输入副本。
- `max_batch`：本机的 3dsmaxbatch.exe。
- `output_dir`：工具包内 `output/过程资产/<新批次>`，目录必须尚不存在。
- 其他字段见 [配置说明](../执行规范/环境与配置.md)。

JSON 中的 Windows 路径优先使用正斜杠；反斜杠需要双写。相对路径基于工具包根目录，而不是配置文件所在目录或终端当前目录。空白样例故意不能执行，不会自动寻找或加载本机旧场景。

## 检查和预览

```powershell
python -X utf8 -B scripts/通用/项目入口.py check
python -X utf8 -B scripts/通用/项目入口.py plan
```

退出码 0 表示本层检查无阻塞，2 表示配置或环境阻塞。检查只验证路径、类型和保护边界，不验证真实软件版本、授权和插件加载。

`plan` 输出参数数组和子进程环境覆盖项，不执行它们；不可把数组当作已运行证据。

## 获准后启动审计

```powershell
python -X utf8 -B scripts/通用/项目入口.py audit --execute
```

审计固定开启 Safe Scene，记录源场景身份、保护范围前后哈希、日志和迁移前置检查。过程可能耗时；中断后先确认所属 Max 子进程已停止，再用新批次重试，不随意终止用户其他软件实例。

输出的 `迁移前置检查.json` 为 `needs_material_mapping_review` 时，仅表示可以继续评估映射，不表示转换完成；`blocked` 时先解决具体阻塞。

若配置启用了 `material_details`，可对真实生成的快照执行离线分析：

```powershell
python -X utf8 -B scripts/诊断/分析材质依赖.py --input "output/过程资产/新场景-首次审计/场景审计.json" --output "output/过程资产/新场景-首次审计/材质依赖分析.json"
```

这条底层分析命令的相对参数按终端当前目录解析，因此请在工具包根目录执行，或使用绝对路径。输出文件不得已存在。

## 不启动三维软件的自检

```powershell
python -X utf8 -B scripts/验证/测试通用入口.py
python -X utf8 -B scripts/验证/测试独立审计.py
python -X utf8 -B scripts/验证/测试材质依赖.py
python -X utf8 -B scripts/通用/分享工具包.py check
```

测试使用临时目录、模拟参数和合成快照；不包含可转换的示例模型，也不验证真实三维软件。检查完成后按 [标准流程](../执行规范/三维场景转换与游戏优化-标准流程.md) 制定下一阶段方案。
