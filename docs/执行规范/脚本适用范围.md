# 脚本适用范围

## 默认可复用入口

| 文件 | 运行环境 | 适用边界 |
|---|---|---|
| scripts/通用/生成六步指南.py | 外部Python标准库 | 六步Markdown生成离线HTML，或只读检查一致性 |
| scripts/验证/测试六步指南.py | 外部Python标准库 | 结构、转义、链接和生成一致性 |
| scripts/验证/测试六步页面交互.cjs | Node.js标准库，仅维护测试 | 模拟交互，不启动浏览器，不代表视觉验收 |
| scripts/通用/项目入口.py | 外部 Python | 配置检查、预览与显式 Max 审计 |
| scripts/通用/项目配置.py | 外部 Python | 配置契约和只读路径检查 |
| scripts/通用/分享工具包.py | 外部 Python | 白名单检查、ZIP 打包和哈希复核 |
| scripts/诊断/运行独立审计.py | 外部 Python，执行时需要 Max | 接收显式源、软件和输出路径；开启 Safe Scene，不转换 |
| scripts/诊断/场景审计.py | Max 内置 Python | 仅由 Max Batch 在正确场景上下文中运行 |
| scripts/诊断/材质依赖审计.py | Max 内置 Python | 基础审计加参数图快照；部分读取必须记录 |
| scripts/诊断/分析材质依赖.py | 外部 Python | 消费对应快照格式，不等于渲染验收 |
| scripts/验证/测试通用入口.py | 外部 Python | 临时目录和模拟子进程，不启动三维软件 |
| scripts/验证/测试独立审计.py、测试材质依赖.py | 外部 Python | 合成数据回归，不使用模型资产 |

具体协议见 [通用入口模块说明](../模块说明/通用入口模块说明.md)。

## 不包含的能力

本仓库不包含场景专用转换、优化、插件迁移、Unity业务写入和历史归档脚本。不要仅从流程描述推断这些实现已经提供，也不要为缺少案例资料自动访问其他工程。

## 适配最低要求

输入和输出参数化；拒绝覆盖；明确原资产保护；可复核的中间清单；先验证代表材质和几何，再做全量；分别提供结构、回读、视觉和目标引擎证据。

不要把所有脚本直接包装成一个按钮。只有接口、失败行为和验收依据明确后，才扩展通用入口。
