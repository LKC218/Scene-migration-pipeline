# 分享与验证

## 分享内容

`configs/分享白名单.json` 是唯一打包清单。仅包含通用入口、审计／分析脚本、离线检查脚本、配置样例、通用文档、六步页面及一张静态流程图。完整项目的模型、贴图、参考图、历史报告、案例脚本和本机配置默认不分发。

给美术人员分享时，请让对方先读README中的美术入口，不要求其先填配置或运行命令。Unity Skills需在对方执行环境中具备，不随包安装。

推荐直接打开`docs/使用指南/场景迁移与优化-六步指南.html`，并把同名Markdown交给Agent。可只转发这两份阅读文件，放在同一文件夹；若要使用审计脚本则分享完整工具包。HTML一次只显示一步，不保存完成进度；切步和复制不会连接软件，也不代表操作授权。

内容更新后，维护者先运行`python -X utf8 -B scripts/通用/生成六步指南.py`。打包会强制核对生成页面与Markdown、模板一致，不允许分享过期HTML或任意网页。

.gitignore 只影响 Git，不会自动过滤 ZIP。请使用本项目打包脚本，不要压缩整个工作目录。

## 检查与打包

在工具包根目录执行：

```powershell
python -X utf8 -B scripts/通用/分享工具包.py check
python -X utf8 -B scripts/通用/分享工具包.py pack --zip dist/三维场景审计工具包.zip
python -X utf8 -B scripts/通用/分享工具包.py verify --zip dist/三维场景审计工具包.zip
```

包名已存在时会拒绝覆盖，应使用新名称。生成目录必须是工具包直属 dist，不允许目录联接或任意外部路径。脚本不删除失败的半成品，也不上传、发布或初始化 Git 仓库。

## 自动检查覆盖

- 白名单文件完整、路径不越界、无符号链接或目录联接。
- 不含源工程、输出、历史案例、二进制资产、缓存或本机配置。
- Python 语法、JSON 解析与 Markdown 文件链接目标存在。
- 指定流程图SVG可解析且只含允许的静态元素与属性，不加载外部资源或执行脚本。
- 指定六步HTML与包内Markdown、固定模板逐字节一致；模板是需要代码审查的受信任源码。
- 常见本机绝对路径、私钥头及部分访问密钥模式。
- ZIP 条目与白名单完全一致，内置文件大小及 SHA256 清单可回读核验。

自动检查不验证网页、Markdown 锚点、所有隐私模式、资产权限或软件授权。内置清单证明内容自洽，不是数字签名；传递时可另核对打包命令输出的整个 ZIP 的 SHA256。

## 独立目录验收

1. 将生成包解压到新的中文且含空格目录，不复制旧 output 或本机配置。
2. 运行 README 中三个离线测试和分享检查。
3. 用空白配置样例执行 check，预期明确阻塞且不创建输出。
4. 配置自己的输入和软件后，重新预览并另行授权真实审计。
5. 记录哪些只在同一台机器的独立目录验证，哪些已在另一台机器实测，不混称跨机通过。

测试中使用的空 .max 和模拟程序文件仅用于路径验证，绝不能称为有效模型或真实软件测试。

## 分发前人工确认

确认代码和文档允许分享；不要替第三方资产或商业软件授予权限。当前工具包未擅自添加开源许可证，若要公开开源，需由权利人选择许可范围和许可证。

检查配置、错误信息和日志是否暴露姓名、目录、客户资料或账号信息。未来新增文件须显式审查后加入白名单，不能用通配符扩大范围。
